# Personal email from a LinkedIn profile URL

Paste a LinkedIn profile URL you already have. The personal email comes back only when the match is exact. A miss is free.

Starting from $30 per 1,000 emails found. You pay when an email is returned. A row with no exact email is not charged.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-personal-email-finder. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You have the profile and you need the personal mailbox.

## When to use a different Actor

You have the email and you need the profile. Use Reverse Email Lookup. That lookup is also the check: the same profile URL coming back means the address belongs to that person.
