# LinkedIn Email Finder

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-personal-email-finder` on Apify: https://apify.com/oday/mawsool-linkedin-personal-email-finder
- Paste a LinkedIn profile URL you already have. The personal email comes back only when the match is exact. A miss is free.
- Starting from $30 per 1,000 emails found. You pay when an email is returned. A row with no exact email is not charged.
- Use it when: You have the profile and you need the personal mailbox.
- Use something else when: You have the email and you need the profile. Use Reverse Email Lookup. That lookup is also the check: the same profile URL coming back means the address belongs to that person.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
